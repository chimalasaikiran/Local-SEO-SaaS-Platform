# Local SEO SaaS Platform

A production-ready Local SEO SaaS platform.

## Getting Started

1. Copy `.env.example` to `.env`:
   ```bash
   cp .env.example .env
   ```

2. Install dependencies:
   ```bash
   pnpm install
   ```

3. Start infrastructure (PostgreSQL & Redis):
   ```bash
   docker-compose up -d
   ```

4. Start development servers:
   ```bash
   pnpm dev
   ```
